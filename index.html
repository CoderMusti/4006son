📋 SETUP INSTRUCTIONS

1. Train Your Teachable Machine Model

  1. Go to teachablemachine.withgoogle.com
  2. Choose Image Project → Standard image model
  3. Create 4 classes: Water, Salt, Ammonia, Benzene
  4. Capture 50–100 images per class using your webcam
  5. Click Train Model, then Export Model → Upload (shareable link)
  6. Copy the model URL and paste it into the game's URL field

2. Run Locally

  1. Place index.html, style.css, script.js in a folder
  2. Serve via a local web server (e.g. npx serve . or VS Code Live Server)
  3. Allow webcam access when prompted

3. Using Local Model Files

Alternatively, download your model (model.json, metadata.json, weights.bin) and place them in a model/ folder, then set the URL to ./model/.
